# Vazhvanthol Eco Tourism - Daily Collection Cashbook

A web-based cashbook application designed for the Chathancode Eco-Development Committee under the Peppara Wildlife Sanctuary to safely manage and track daily visitor collections at Vazhvanthol Waterfalls.

## Key Features
* **Daily Package Entry:** Separate and precise record-keeping for Indian and Foreigner visitors on the same date.
* **Automated Fee Calculation:** Automatically calculates Total Income, Guide Fee, Sanctuary Entrance (Rr), EDC Share, and EMF based on the number of visitors, packages, and holiday/weekend status.
* **Payment Tracking:** Systematically records payments received via EPOS, UPI, and Cash, along with daily bank remittance details.
* **Dynamic Monthly Abstract:** Auto-generates a consolidated monthly summary report based on the selected Financial Year (April to March).
* **Print & Export:** Fully optimized, print-ready layout for generating daily cashbook reports and monthly abstracts as PDFs.
* **Cloud Storage:** Secure, real-time data storage and retrieval using Google Firebase Firestore.
* **Responsive Layout:** Works flawlessly across both desktop computers and mobile devices.

## Technologies Used
* HTML5 & CSS3
* Vanilla JavaScript
* Firebase (Cloud Firestore)
